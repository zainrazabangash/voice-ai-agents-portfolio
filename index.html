Voice AI Agents Portfolio

Three production-grade voice agents built on Retell AI, demonstrating receptionist automation, outbound sales qualification with CRM integration, and knowledge-base-driven customer support.

About this portfolio

Each agent below is a fully functional voice AI built using Retell AI as the voice platform, GPT-4.1 / GPT-4.1 Mini as the language model, and integrated with real backend systems (Cal.com, Airtable, n8n, custom knowledge bases) to perform actual tasks, not just hold demo conversations.

Click any "Try" button below to talk to the agent live in your browser. You will need to allow microphone access.

🦷

Sophia

Dental Clinic Receptionist (Inbound)

Handles inbound patient calls for a dental clinic. Answers FAQs about hours, services, insurance, and pricing. Books new patient appointments via Cal.com integration. Triages dental emergencies with the right urgency.

Single-prompt GPT-4.1 Cal.com Function calling
📊

Brian

SaaS Sales Qualifier (Outbound)

Outbound sales development representative for a SaaS product. Conducts BANT qualification (Budget, Authority, Need, Timeline) across a multi-node conversation flow. Logs every lead to an Airtable CRM via n8n webhook in real time.

Conversation Flow GPT-4.1 n8n Airtable Webhooks
🛍️

Lily

E-commerce Customer Support (Inbound)

Customer support agent for an online children's clothing shop. Uses a knowledge base to answer product, sizing, shipping, and returns questions. Escalates order-specific and complex issues to the human team via WhatsApp.

Single-prompt GPT-4.1 Mini Knowledge Base RAG
